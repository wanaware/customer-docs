## Transcript

Integrations bring supported source data into WanAware. The provider-specific fields vary, but every setup ends with the same check: find a known imported asset.

Open Administration, Integrations, choose the intended provider, and select its connect action. Confirm the WanAware company before entering setup details.

Follow the matching provider adapter, use the least supported access, and save. Authorization values stay out of recordings and support messages.

Select **Test connection**, then use the released inventory refresh action. Wait for WanAware to accept each request.

If you are importing a file instead, download the current template, select **Upload & Validate**, resolve every blocking row, and then select **Confirm & Normalize**.

Open Assets, Inventory, clear filters, and search for one sample Asset by its exact name. Confirm its Asset Type, source context, and unique identifier.

A connected status alone is not the finish line. Verify known inventory, then use the written troubleshooting steps if it is missing.
