## Transcript

This walkthrough shows both ways to add assets: one at a time or in bulk. Your available actions depend on your role and the asset type.

Choose Add Asset. Select the asset type, choose Inventory or Discovery, enter the fictional name `demo-router-01`, and add only non-sensitive data tags. Review the values before saving.

Save the asset. A success message confirms that WanAware accepted it. Select View Asset to verify the name, type, and status.

Return to Assets and search for `demo-router-01`. If it is missing, clear filters and check both Inventory and Discovery.

When Bulk Upload is available, open it and download the current template. Do not reuse an old template because required columns may have changed.

Upload the sanitized file and review validation messages by row. Correct the source file rather than guessing at rejected values, then upload it again.

Search for one imported asset and verify its details. The written article has recovery steps and the Support evidence checklist. Never put credentials or secret values in an import file.
