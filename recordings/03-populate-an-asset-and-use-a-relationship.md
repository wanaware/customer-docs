## Transcript

Start by confirming the asset name, Asset Type, and source identifier. Edit only fields you own and that the source will not immediately overwrite.

Update the editable name, add an approved Data Tag, and select the intended Structure Tag. Matching names alone do not attach the asset to a Structure.

Complete required fields and choose approved Service Catalog values. Review dependent choices, then use the unsaved-change bar to save everything.

Refresh the page. The saved name, tags, and field values should remain.

For an eligible asset, select Add Connection. Choose the target asset, IP block, and endpoints, then select Preview Connection.

Confirm the source, target, block, and endpoints before selecting Create Connection. WanAware confirms that the network connection was created.

Open Relationship Graph, clear filters, and confirm the target asset. Use this specific flow only for supported network connections.
