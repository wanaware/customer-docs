An **Asset Type** defines an asset's sections, fields, and dependencies. Its **Service Catalog** provides managed choices such as manufacturers, models, components, software, specifications, attributes, and compatibility.

Keep a custom Asset Type as a draft while you configure its schema and catalog. Publish only after both are ready, because publishing can make the custom schema read-only.

## Learn

- [Understand Asset Types and Service Catalogs](https://docs.wanaware.com/docs/understand-asset-types-and-service-catalogs)

## Set up an Asset Type

1. [Create a custom Asset Type](https://docs.wanaware.com/docs/create-a-custom-asset-type).
2. [Configure its sections and fields](https://docs.wanaware.com/docs/configure-asset-type-sections-and-fields).
3. Configure the Service Catalog while the Asset Type remains a draft.
4. [Publish and verify the Asset Type](https://docs.wanaware.com/docs/publish-and-verify-an-asset-type).
