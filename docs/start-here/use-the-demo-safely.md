# Use the demo safely

**Outcome:** Explore the product and complete useful tasks without disrupting a shared environment.

**For:** Anyone using a WanAware demo or shared evaluation workspace
**Permission:** Varies by account
**Time:** 5 minutes
**Changes made:** None unless you choose a write action

## Safe actions

These actions are normally safe in a shared demo because they do not change the underlying records:

- Search, filter, sort, and paginate tables
- Switch between table and graph views
- Open an asset, Element, Collection, Structure, monitor, Worker, or Pulse execution
- Explore relationship graphs and change visual grouping or depth
- Review company, role, and subscription information you already have permission to see
- Copy a non-sensitive identifier for a support request

## Ask before doing these

These actions change shared data or behavior. Confirm with the demo owner first:

- Add, edit, move, attach, detach, archive, deactivate, or delete a record
- Invite a user or change a role
- Connect, test, crawl, replace, or delete an integration
- Add, pause, resume, reassign, or delete a monitor or Worker
- Run a bulk import
- Change company, billing, branding, security, or notification settings

## Never enter or upload

- Production credentials, passwords, tokens, private keys, or cloud secrets
- Real customer data unless WanAware has explicitly approved that workspace for it
- Personal data that is not required for the evaluation
- Files containing credentials or internal infrastructure details

## If you make an accidental change

1. Stop before making another change.
2. Record the page URL, affected record name or ID, time and time zone, and the action you selected.
3. Do not try to hide the change by deleting more records.
4. If the UI has a clear, verified undo action, use it once.
5. Otherwise email [support@wanaware.com](mailto:support@wanaware.com?subject=Accidental%20change%20in%20WanAware%20demo) and describe what happened.

## Check your result

You are ready to continue when you know which actions are read-only, which actions need approval, and where to report an accidental change.
